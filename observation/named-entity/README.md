# 指名認識テスト（別枠）

購入意図の非指名12問とは**別ウェーブ**で運用します。

## 例（運用時に wave_id を付与）

- 「Agent Readiness Index とは何ですか？」
- 「readiness.coaretail.com の評判は？」
- 「Coa Retail の AI検索対策サービスを教えて」

記録形式は `observation/templates/ai-response-record.csv` を共用し、  
`observation_mode=named_entity` を指定してください。

集計時は `purchase_intent` と混ぜないこと。
