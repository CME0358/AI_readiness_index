# LinkedIn Executive Note — Theme 3

## Post copy（目安: 650字）

「SEOとGEO、どちらを優先すべきですか？」

この問い自体、レイヤーが混ざっていることが多いです。

整理するとこうなります。

**SEO** → 検索流入（Search visibility）
**GEO/AEO** → AI回答での引用・発見（Answer visibility）
**Agent Readiness** → 理解・比較・推薦・行動（Business / Recommendation Readiness）

競合概念ではなく、見る段階が違います。

現場でよくあるパターン:
・SEOで流入はあるがAI回答に出ない
・GEOで引用されても予約に至らない
・施策は増えたがKPIが混同され、効きどころが見えない

同じページ改善が複数レイヤーに効くこともあります。
ただし、測定単位と担当は分けるべきです。

Agent Readinessは「全部ARIをやれ」という意味ではありません。
経営と現場が、同じ状態を共有するための評価言語です。
