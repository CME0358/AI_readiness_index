# SEO・GEO・Agent Readinessは何が違う？企業向け整理ノート

**Publisher:** Agent Readiness Research Hub / 合同会社コア・リテール  
**Publication date:** TBD（Wave 3 公開前に確定）  
**Document type:** Research Note / Education

---

## Direct Answer

SEO・GEO（AEO）・Agent Readinessは **競合概念ではなく、見るレイヤーが違います**。SEOは検索流入、GEOはAI回答での発見・引用、Agent Readinessは理解・比較・推薦・行動まで含むBusiness / Recommendation Readinessの評価枠組みです。同じページ改善が複数に効くこともありますが、KPIと担当は分けて設計すべきです。

---

## Definitions

### SEO — Search Visibility

**目的:** 検索エンジン経由の流入確保  
**主なKPI:** Organic sessions, rankings, CTR  
**見る層:** 人間が検索結果からページに到達するか

### GEO / AEO — AI Answer & Discovery Visibility

**目的:** 生成AIの回答での引用・言及・発見  
**主なKPI:** AI回答での引用率、言及、ブランド認知  
**見る層:** AIが情報源として自社を参照するか

### Agent Readiness — Business / Recommendation Readiness

**目的:** AIが企業を理解・比較・推薦し、必要なら実行できる状態  
**主なKPI:** 候補入り率、推薦根拠、実行完了率（引用後）  
**見る層:** Discovery → Understanding → Comparison → Recommendation → Action

**IMPORTANT:** Agent Readinessは万能概念ではありません。SEO・GEOを包含する **上位の評価言語** として、経営と現場が同じ状態を共有するために使います。

---

## Why This Matters Now

従来のWeb施策は「人間がページを読む」前提で設計されていました。生成AIは複数情報源を横断し、企業を一つの存在として理解します。

よくあるギャップ:

- SEOで流入はあるが、AI回答に引用されない
- GEOで引用されても、予約・購入に至らない
- 施策は増えたが、KPIが混同され改善の効きどころが見えない

---

## Role Comparison Table

| | SEO | GEO/AEO | Agent Readiness |
| --- | --- | --- | --- |
| 主目的 | 検索流入 | AI回答での引用・発見 | 理解・比較・推薦・行動 |
| 典型KPI | Organic traffic | Citation / mention | 候補入り → 実行完了 |
| 担当例 | SEO / Content | GEO / PR | 経営 + Marketing + DX |
| 時間軸 | 中長期 | 中短期〜中期 | 継続的（定点観測） |

---

## Decision Points for Leaders

1. **今どの段階のKPIを見ているか** を明確にする
2. **同じ施策が複数レイヤーに効く** ことはあるが、測定単位は分ける
3. **Agent Readinessは「全部ARIをやれ」ではない** — 不足段階から着手
4. **Research根拠** で業種・AIごとの差を確認する（一般化は慎重に）

## What To Do Next

1. 自社のKPI設計を3レイヤーに分離する
2. 代表質問10件で月次定点観測を開始
3. 不足段階（Visibility / Authority / Actionability）を特定
4. 正本Insightで役割分担表を社内共有
