# Evidence Brief — Theme 1

**Title:** ChatGPTに自社が出ない現象 — 5段階フレームワークと観測データ

## Executive Summary

WebサイトとSEO施策があっても、生成AIの推薦候補に自社が入らないケースは増えています。本Briefは、現象を **Discovery → Understanding → Comparison → Recommendation → Action** の5段階で読み解くDecision Frameworkと、Agent Readiness Researchの観測データを経営・Marketing向けに要約したものです。

---

## Key Findings

1. **AI認識は検索順位と独立する** — AIはページ単位ではなく企業エンティティとして情報を統合する。
2. **止まりどころは段階ごとに異なる** — 発見以前・理解不足・比較不能・推薦根拠不足・行動導線不足のいずれかで中断する。
3. **業種格差が観測される** — 5業種231件の調査で、不動産97.8% vs 士業15.6%（約5.5倍）の推薦率差を確認（Research Edition 2026）。
4. **定点観測が改善の起点** — 代表質問10件の月次記録が、感覚論を排除する。

---

## Decision Framework

| 段階 | 問い | 最低条件 |
| --- | --- | --- |
| Discovery | AIは自社の存在を外部から確認できるか | 名称・所在地・連絡先のチャネル間一致 |
| Understanding | 何を誰向けに提供するか一貫しているか | 具体的事実・条件の明示 |
| Comparison | 他社と並べた差分が構造的か | 比較項目の一覧化・更新 |
| Recommendation | 推薦してよい根拠があるか | 第三者情報との整合 |
| Action | 実行に進めるか | 予約・問合せ・購入導線の明確化 |

## Limitations

- 231件は5業種横断の観測であり、全業種・全地域への一般化は不可。
- 一部AI推薦率はクロス検証値・推定値を含む。
