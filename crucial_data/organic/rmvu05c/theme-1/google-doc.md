# ChatGPTに自社が出ないときに確認する7項目

**Publisher:** Agent Readiness Research Hub / 合同会社コア・リテール  
**Publication date:** TBD（Wave 1 公開前に確定）  
**Document type:** Research Note / Checklist

---

## Direct Answer

ChatGPTや他の生成AIに自社が出ない場合、検索順位だけの問題ではありません。多くの企業は **Discovery（発見）→ Understanding（理解）→ Comparison（比較）→ Recommendation（推薦）→ Action（行動）** のどこかで止まっています。まず「どの段階で止まっているか」を特定し、そこから優先順位を決めるのが合理的です。

---

## Why This Happens

Googleはページをインデックスします。生成AIは、企業を一つの **エンティティ（存在）** として理解しようとします。公式サイト・地図・SNS・第三者メディアなど複数ソースを照合し、「同じ会社か」「何を提供する会社か」「推薦してよいか」を判断します。

Webサイトがあっても、情報が分散・矛盾・曖昧・非構造・行動導線不足の状態では、AIは候補に上げられません。

---

## Checklist — 7 Decision Points

### 1. Discovery — 外部から企業の存在が確認できるか

- [ ] 公式サイト以外（Googleビジネスプロフィール、業界ポータル等）で会社名・所在地が一致している
- [ ] 法人名とブランド名の関係が第三者にも分かる
- [ ] 主要チャネルで電話番号・住所表記が統一されている

**止まりどころ:** ここでNo → AIはそもそも「同じ会社」と結び付けられない

### 2. Understanding — 何を誰向けに提供するかが一貫して読めるか

- [ ] サービス内容が抽象コピーではなく具体的事実で書かれている
- [ ] 対象地域・業種・条件が明示されている
- [ ] 料金・営業時間・提供範囲が公式情報で確認できる

**止まりどころ:** ここでNo → 比較対象にできない

### 3. Comparison — 他社と並べたとき差分が構造的に取れるか

- [ ] 比較に使われる項目（名称・所在地・提供内容・条件）が一覧化されている
- [ ] 競合と並べても自社の特徴が事実ベースで説明できる
- [ ] 更新日・根拠が古くない

**止まりどころ:** ここでNo → 推薦理由が形成されない

### 4. Recommendation — 第三者情報と整合し、推薦してよい根拠があるか

- [ ] レビュー・メディア・業界団体など外部からの裏付けがある
- [ ] 公式情報と第三者情報に矛盾がない
- [ ] 誇大表現より検証可能な事実が中心

**止まりどころ:** ここでNo → 引用はあっても推薦に至らない

### 5. Actionability — 予約・問い合わせ・購入に進めるか

- [ ] 予約・問い合わせ・購入の導線が明確
- [ ] AIエージェントが「次の行動」を想像できる情報設計
- [ ] 実行導線を一つ通してテスト済み

**止まりどころ:** ここでNo → 紹介されても実行で止まる

### 6. Structural clarity — 機械が意味を正確に読めるか

- [ ] 営業時間・所在地・サービス等が構造化データ（Schema.org等）で提供されている
- [ ] 人間向け文章と機械向け構造の両方が整っている

**注:** 技術信号は手段。Discovery〜Actionのどこで止まっているかを先に見る。

### 7. Observation — 定点観測で事実を記録しているか

- [ ] 代表質問（業界・地域・用途別）を10件程度決めている
- [ ] 月次でAI回答を記録し、自社が候補に入るか確認している
- [ ] 感覚ではなく観測に基づいて改善優先順位を更新している

## Research Evidence

当社調査（Agent Readiness Research）では、以下を確認しています。

| 調査 | 内容 | 参照 |
| --- | --- | --- |
| 100問調査 | 主要AI5社への質問設計・回答分析 | Agent Readiness Research |
| 5業種231件 | 歯科・美容・フィットネス・不動産・士業、25クエリ、231件のAI回答 | Evidence Library / Whitepaper 2026 |
| 業種格差 | 不動産97.8% vs 士業15.6%（約5.5倍の推薦率差） | Research Edition 2026 |

**Limitations:** 231件は5業種横断の観測データであり、すべての業種・地域に一般化できるわけではありません。各AIの推薦率はクロス検証値を含み、推定値が混在します。

## What To Do Next

1. 上記7項目で最初の **No** が出た段階を特定する
2. その段階の情報オーナーと更新ルールを決める
3. 代表質問10件で月次定点観測を開始する
4. 一般論ではなく、**自社がどの段階で止まっているか** を可視化する
