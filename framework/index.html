Frameworkとは

Agent Readiness Frameworkは、AIが企業を理解する（Discovery）、比較・推薦する（Recommendation）、予約・問い合わせなどを実行する（Action）までを評価するフレームワークである。

SEOやGEOを包含し、AI Agent時代の企業評価基準として設計している。

Framework評価基準 → Index診断指標 → Improve改善提案

各レイヤーの評価要素

Discovery

  • Schema.org
  • FAQ
  • コンテンツ構造

Recommendation

  • 料金公開
  • 実績
  • 比較情報
  • E-E-A-T

Action

  • 予約
  • 問い合わせ
  • リアルタイム情報
  • 情報整合性

Framework誕生の背景

AI5社への独自調査から、共通して現れた評価原理を分析し、DRAモデルとして体系化した。

なお、AI内部アルゴリズムを解明したものではなく、AIが企業評価について語る際の共通傾向を整理したFrameworkである。
