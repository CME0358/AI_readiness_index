ChatGPTに出ないときの確認手順

サイトがあるのにAI回答に自社が出ない場合、検索順位だけでは説明できません。Discovery → Understanding → Comparison → Recommendation → Action のどの段階で止まっているかを切り分けます（詳細は AIに会社が出ない原因5つ）。

手順1 — 無料で公開面を確認（メール不要）

  1. トップの無料簡易確認に公式サイトURLを入力
  2. 表示されるのは公開ページから読み取った手がかりであり、点数・AI実測スコアではありません
  3. 接続できない場合は再試行ボタンまたは 無料ガイド へ

手順2 — 典型原因5つをチェック

  1. 情報の分散（公式・GBP・媒体で会社名・住所が不一致）
  2. サービス説明の曖昧さ（比較軸になる属性が不足）
  3. 構造化・意味設計の不足（Schema / エンティティ一貫性）
  4. 第三者シグナルの不足（Trust / Reviews）
  5. Action 導線の不明確（予約・問い合わせ・購入までの記述）

チェックリスト形式は Visibilityチェックリスト に整理済みです。

手順3 — 詳細診断が必要なとき

  • Company Report（¥29,800・税別）— 23項目・4大AI認識・優先順位（入力後約3分）
  • 店舗・クリニックは Local GEO（月額¥60,000・税別）へ
  • 判断に迷う場合は 無料相談

検証可能な根拠（研究）

  • Agent Readiness Research — 主要AIへの100問調査・5業種231件観測
  • Evidence Library — 公開データへのリンク

個別クライアントの来店数・売上インパクトは本ガイドでは断定しません。Bar SECRET は観測層と申告層を分けて掲載しています。
