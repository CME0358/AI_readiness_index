  1. 2026.07.07 Press Release

    AIに見つかる時代から、AIに選ばれる時代へ — Agent Readiness Frameworkを公開

    主要AI5社（ChatGPT・Claude・Gemini・Perplexity・Grok）への独自調査100問をもとに、企業がAIに理解・比較・推薦・実行される状態を評価する「Agent Readiness Framework（DRAモデル）」を公開。Research Hub・ホワイトペーパー・診断ツールを同時公開。

    PR TIMES Framework Research Hub Whitepaper
  2. 2026.06.16 Press Release

    AI検索の勝者は店舗ではなかった — 5業種調査で見えた「業界インフラが推薦を支配する時代」

    Claude Sonnetを対象に歯科・美容・フィットネス・不動産・士業の5業種でAIブランド推薦率を定量比較。業種間で最大5.5倍の格差を観測し、Agent Readiness Index™（ARI）を公開。
